# Geodesus — 4X Strategy Game Engine

Geodesus is an ambitious, custom-built 4X strategy game running on a dual geodesic grid globe. This project represents a deep dive into complex spatial data structures, custom algorithmic mathematics, and fully editable world generation.

## 🛠️ Technical Implementation Details

- **Grid Architecture:** Dual geodesic coordinate mapping system optimized for performance and fluid pathfinding across global cell borders.
- **Data Pipeline:** Procedural asset allocation handling simulation state updates independently from visual assets.
- **Asset Optimization:** Repository files are currently stripped of heavy graphical assets for optimal repository storage.
